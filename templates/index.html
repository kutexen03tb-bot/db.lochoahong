Bắt đầu với LinkScope

1. Nhập danh sách sản phẩm

Dán một cột link hoặc tải Excel/CSV và chọn cột chứa link. File Excel đọc sheet đầu tiên, hỗ trợ URL trong hyperlink. Dùng link đầy đủ hoặc Item ID; hãy tự mở link rút gọn để lấy link gốc. Tool gộp các link có cùng Item ID.

2. Nhập API Key rồi kiểm tra

Lấy key từ addlivetag.com → API Key → Tạo Key. API yêu cầu key từ 01/10/2026. Tỷ lệ HH sàn nhập theo đơn vị % (ví dụ 3,5); để trống nếu muốn dùng tỷ lệ API trả về. Nếu sàn trả 0%, API giữ 0% theo tài liệu.

Chế độ thường gửi từng lô 20 sản phẩm, cách tối thiểu 15 giây giữa các lô. Chỉ cache: 100 sản phẩm/lô, cách 4 giây. Tool tôn trọng 429 và cooldown của nguồn. Dừng sẽ không gửi lô tiếp theo; lô đang chạy vẫn hoàn tất.

3. Lọc và xuất

Lọc theo giá, tổng % HH hoặc số tiền; Excel/CSV chỉ xuất các dòng đang khớp bộ lọc, trên tất cả các trang. Mục thiếu thông tin hiển thị “—”, không tự coi là 0.

Đọc đúng dữ liệu

Giá là trường price do API trả, không đảm bảo giá cuối sau voucher hay mọi biến thể. Tổng % dùng totalRatePercent hoặc tổng hai tỷ lệ thành phần, không lấy tiền HH chia giá để thay thế. Bấm nút thông tin ở mỗi dòng để xem tỷ lệ thực nhận theo phép chia này, nguồn, trần và thời gian cập nhật.

Dữ liệu từ API bên thứ ba, cache khoảng 3 giờ hoặc cũ hơn khi nguồn lỗi. Không phải cam kết được thanh toán. Tài liệu giới hạn học tập/nghiên cứu/nội bộ phi thương mại.

Lịch sử giá & hoa hồng

Dùng API thứ hai price-tracking/history.php, tối đa 50 sản phẩm/lô. Tool chờ 6 giây giữa lô, tải tối đa 500 sản phẩm mỗi thao tác. Tùy chọn kèm lịch sử khi kiểm tra hoặc tải riêng danh sách đã lọc. Chỉ lấy mốc đổi giá / tổng % HH, không lấy mọi biến động trong ngày.

Quan trọng: điền HH sàn và trần đúng tài khoản. Không khai thì lịch sử có thể đổi giả do hệ thống dùng các tài khoản thu thập khác tier. Tool giữ cảnh báo và các điểm suspect. Lịch sử rỗng khác với hoa hồng 0. Tổng đã bán là lịch sử bán tích lũy từ Batch, không phải doanh số từng ngày.

Quyền riêng tư

Key và kết quả chỉ nằm trong bộ nhớ khi dùng; không dùng localStorage, không ghi key vào log/file. File nhập được gửi tới máy chủ tool để đọc; key và Item ID được gửi đến AddLiveTag khi bạn kiểm tra. Tải lại trang sẽ mất dữ liệu. Nên tự chạy trên máy nếu cần giữ danh sách riêng tư.
